# VPSChecker

[English version](README.md)

VPSChecker — небольшая терминальная утилита для оценки пригодности VPS в качестве
выходной VPN-ноды. Она должна проверять репутацию IP-адреса, доступность сервера
из России и внешнюю доступность портов VLESS и Hysteria2. Репутация, региональная
доступность и состояние сервисов оцениваются раздельно, а проверки выполняются с
минимальными изменениями системы.

Сейчас реализованы CLI, валидация параметров и read-only preflight. Preflight
определяет ОС, текущие права, внешний IPv4, наличие нужных команд и APT-пакетов,
а также локальные TCP/UDP listeners. Он не устанавливает пакеты и не вызывает
`sudo`.

После preflight утилита загружает `xykt/IPQuality` версии `v2026-08-09` из
закреплённого commit и проверяет SHA-256. IPQuality запускается для IPv4 с полным
локальным JSON, privacy mode и отключённой установкой зависимостей. Успешный
исходный JSON не преобразуется и хранится во временном каталоге текущего запуска.
Его разбор и формирование оценки относятся к следующему шагу.

Если отсутствуют необходимые APT-пакеты, VPSChecker показывает их список и
запрашивает подтверждение. После подтверждения выполняется `apt-get update`,
затем устанавливаются отсутствующие пакеты без рекомендаций. Общий `upgrade` и
`autoremove` не запускаются.

```bash
./vps-check.sh
```

По умолчанию проверяются TCP/443 для VLESS и UDP/443 для Hysteria2. Любой порт можно переопределить:

```bash
./vps-check.sh --ip 203.0.113.10 --vless-port 2053 --hysteria2-port 8443
```

`--ip` можно не указывать: утилита определит внешний IPv4 через HTTPS. Явное
значение позволяет пропустить отдельный запрос для автоопределения адреса.

Обновление закреплённой версии IPQuality:

```bash
./scripts/update-ipquality.sh
```

Можно проверить конкретный полный commit SHA:

```bash
./scripts/update-ipquality.sh COMMIT_SHA
```

Скрипт проверяет текущий исходный файл, загружает кандидата, показывает его
checksum и diff, после чего запрашивает подтверждение перед изменением фиксации.
